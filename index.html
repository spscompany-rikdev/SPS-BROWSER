Privacy & security

Why you can trust it — and how to check

We would rather show you than ask you to take our word for it.

📖

Open source

The code is public on GitHub. Anyone can read it, build it and report problems.

View the code →
✋

Websites must ask first

Camera, microphone, location, notifications and other permissions start as “ask”. Unknown permission types are denied.

🔑

Passwords stay with you

Passwords are stored encrypted on your computer. On Windows the key is tied to your Windows account. There is no SPS cloud.

🔢

Check your download

Every release lists SHA-256 checksums. Compare them with the file you downloaded — steps are in the download section below.

📡

No accounts, no analytics

The browser has no sign-up and no usage tracking. It only talks to the sites you open and to the update server when it checks for updates.

🧱

Protected start-up

A small launcher starts the browser in a protected way and offers a safe-mode restart if something goes wrong.

No software is perfectly secure. If you find a problem, please open an issue on GitHub.

FAQ

Questions people ask

Is SPS Browser really free?

Yes. It is free to download and use, with no subscription and no ads inside the browser. The source code is open on GitHub.

Does it collect my data?

No accounts and no usage analytics. The browser connects to the websites you open and, when you allow it, to the update server to look for new versions. Your passwords, history and bookmarks stay on your device. See the privacy policy in the GitHub repository for details.

Windows says “Windows protected your PC”. Is it safe?

That screen appears for software without a paid publisher certificate. Click “More info”, then “Run anyway”. To be extra careful, download only from the official release page and compare the SHA-256 checksum as shown in the download section.

Which systems does it run on, and how much memory do I need?

Windows 10 or 11 (64-bit) is the main version, with an installer and a portable zip. There are also builds for macOS 12 or newer on Apple Silicon, 64-bit Linux (Ubuntu 22.04 or newer) and Android 7.0 or newer. For normal browsing about 2 GB of free RAM is enough. To run the built-in AI models well you need at least 12 GB of free RAM. Windows is the most tested version.

Do I need a powerful computer for the AI features?

Only for the optional local AI models: at least 12 GB of free RAM is needed for them to run well. The AI hub, which opens ChatGPT, Gemini, Claude and others in a tab, runs on the websites' own servers and needs no extra memory from you. Normal browsing needs about 2 GB of free RAM.

Do I need to install Python?

No. The Windows installer includes everything it needs.

Can I use Chrome extensions?

Yes. You can install Chrome-style extensions, and they show in the toolbar with their own icon. Some extensions that rely on Google-only services may not work.

Can I bring my bookmarks and passwords?

Bookmarks: use ⋮ → Import Bookmarks with an HTML or JSON export from Chrome, Edge or Firefox. Passwords: the Password Manager can import a CSV export.

How do the password lock and the one-time code work?

In the Password Manager choose “Set password”. The browser shows a 6-digit code as a normal system notification; type it in, then choose your password. If you forget it, “Forgot password?” sends a new code and turns the lock off — your saved passwords are kept. Because the code appears on the same computer, lock your computer when you step away.

How do I update?

The browser can check for updates and verifies the download before installing. You can also download the newest release from the release page.

How do I report a problem or suggest something?

Open an issue on the GitHub repository. Please include your Windows version and what you were doing.

Trust

Code signing policy

Free code signing for the Windows files of SPS Browser is provided by SignPath.io, with a certificate from the SignPath Foundation.

This applies once SignPath has accepted the project. Until then the Windows files are not yet signed; see the download section for how to check them with a SHA-256 checksum.

What is signed

Only files built from the public source code by the public GitHub Actions workflow: the Windows installer and the program files inside it. Nothing from other projects is signed with this certificate.

How a release is signed

GitHub Actions builds the release from a version tag and sends it to SignPath. An approver checks the request and approves each release by hand. The signed files are published on the GitHub Releases page with SHA-256 checksums.

Team roles

Authors and reviewers: spscompany-rikdev. Approver: spscompany-rikdev. All team members use multi-factor authentication.

Privacy statement

SPS Browser has no accounts and no usage analytics, and the project runs no server that receives your data. The only network requests are the websites you open and the optional services listed in the privacy policy, which is also shown during installation.
